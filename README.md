# ssrfmcp has moved into mcpscan

`ssrfmcp` is now the **`mcpscan ssrf`** module of the [**mcpscan**](https://github.com/cognis-digital/mcpscan) security suite — scan, harden, gate, and pin your MCP servers from one command.

```bash
pip install cognis-mcpscan
mcpscan ssrf --help      # the standalone `ssrfmcp` command still works too
```

This repository is **archived (read-only)**. All development continues in [mcpscan](https://github.com/cognis-digital/mcpscan). Nothing was lost — every feature and command lives on there.
